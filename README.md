## PDF y QR

La tarjeta se puede descargar o compartir como archivo PDF. El botón QR permite elegir entre la página web y el PDF directo. Cuando el navegador no admite compartir archivos, se descarga el PDF para enviarlo desde el teléfono. Los enlaces de Facebook, Maps y WhatsApp también funcionan en el PDF.
